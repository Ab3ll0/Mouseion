Origins:

In The Year 2024 I was tasked with making a GUI-powered Java program for my I.T. Practical.Assessment.Task. (PAT). I had decided to go with a type of program that acted as both a person's literature archive but also a place to seek more literature, or to put more simply, a pocket "Library of Alexndria". This Java project, along with its documentation, took me almost three full months. This is because of obvious reasons such as other school work as well as the complexity of the project. Though in the end I managed to score 100 for the assessment. Now I want to bring this idea in a webpage format as my first true passion project for fullstack development. Enjoy using this website as I enjoyed making it. :)
